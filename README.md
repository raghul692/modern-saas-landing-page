## Introduction
------------

Welcome to the Modern SaaS Landing Page template. This template is designed to help you create a modern and sleek landing page for your SaaS application. It includes all the necessary features to showcase your application's features and benefits.

## Features
----------

* Responsive design that adapts to all screen sizes
* Modern and sleek UI/UX design
* Easy to customize and extend
* Includes features like hero section, features section, testimonial section, and call-to-action section
* Built with HTML, CSS, and JavaScript

## Getting Started
---------------

To get started with the Modern SaaS Landing Page template, follow these steps:

1. Clone the repository using the command `git clone https://github.com/raghul692/modern-saas-landing-page.git`
2. Navigate to the project directory using the command `cd modern-saas-landing-page`
3. Open the `index.html` file in your favorite code editor or browser to view the landing page

## Technologies Used

* CSS3

* Bootstrap 5
